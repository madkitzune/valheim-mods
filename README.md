# Valheim mods

My Valheim 1.0 modpack work: BepInEx plugins and a wiki generator for a Vortex-managed modded install.

| Folder | What it is |
| --- | --- |
| `drawers-save-guard/` | Harmony plugin that makes the mkz Item Drawers work with Path of Valheiman's "stack nearby" and crafting from nearby containers. Redirects `Container.StackAll` / `Save` for drawer containers. |
| `axe-plates/` | Plugin (Jotunn) that adds craftable plates for ancient axes: per-metal bonuses, a procedural mesh, state synced to other players. See its own README. |
| `arcane-armory/` | Work in progress: a grid of new weapons (kind x progression stage) with reusable effects built on the Path of Valheiman API. Design notes in `DESIGN.md`, first wave in `WAVE1.md`. |
| `wiki/` | Static wiki of the whole pack (800+ pages, 900+ settings), generated by `build.py` from localisation, configs and Epic Loot data. `wiki.html` is a ready demo: open it in a browser. |

Notes:
- The plugins compile against the game's managed DLLs and other mods' assemblies, which are not included. Adjust the paths in the `.csproj` files.
- The wiki demo embeds item images that belong to the authors of Path of Valheiman and Valheim; they are there for demonstration only. The data and image folders needed to rebuild it are not included.
- Documentation is partly in Russian.
