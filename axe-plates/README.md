# Axe Plates (обухи для Древних топоров)

BepInEx-плагин для Valheim 1.0.21 (`local.axeplates`). Нужен Jotunn; мягкие зависимости: Path of Valheiman, Epic Loot, Item Drawers.

## Что делает
- «Древние топоры» = предмет **Early Axes** (`AxeEarly`, `$item_axe_early`). Список целей меняется в конфиге (`Targets`; `@axes` = все топоры).
- На кузнице крафтятся **Обухи** из слитков + гвоздей того же металла: бронзовый, железный, серебряный, из чёрного металла, из кровавого золота (Bloodgold, Nord), **громокровный** (Thunderblood: золото + громокровная сущность), **огнеледяной** (Frostfire: золото + огнеледяная сущность). Огнеметалл (Ashlands) исключён.
- Гвозди: ваниль для бронзы и железа; для серебра, чёрного металла и золота мод добавляет свои гвозди (1 слиток -> 12 гвоздей, кузница).
- Применение: перетащить обух мышью на топор в инвентаре. Топор остаётся тем же предметом (качество, прочность, данные PoV/Epic Loot сохраняются), в `m_customData` пишется ключ `axeplates.material`. Новый обух заменяет старый (старый пропадает).
- Бонусы: % урона (рубящий/колющий/дробящий) + прибавка к уровню инструмента (`m_toolTier` удара) + для громокровного молния, для огнеледяного лёд и огонь. Подсказка предмета показывает строку про обух.
- Вид: процедурная изогнутая полоса с рядом гвоздей по режущей кромке головки топора (в руке и на земле); материал берётся с модели слитка. Материал обуха передаётся другим игрокам через ZDO-поле `axeplates.r` на игроке.

## Цепочка кровавого золота (обновление)
- Обух из кровавого золота: ингредиенты формы берутся из ванильного рецепта заготовки `AxeGoldUncooked` (нордская форма, существующая), заготовка обуха делается на станции/уровне этого рецепта (Чёрная кузница), закалка на станции/уровне рецепта `AxeGold` (ледяная кузница). Станции читаются из ObjectDB при старте (см. лог `proto ...`).
- Громокровный/огнеледяной: обух из кровавого золота + золото + сущность, станция/уровень от `AxeGold_BloodLightning` / `AxeGold_FrostFire`.
- Вид: обух с толщиной, выступает из лезвия; на обоих топорах пары; свечение у громокровного (электрическое) и огнеледяного.

## Установка
Скопировать `AxePlates.dll` в `Valheim/BepInEx/plugins/AxePlates/`. Сборка: `dotnet build -c Release` (SDK 8, пути в `AxePlates.csproj`).

## Другу
Мод нужен и ему (добавляет предметы; `NetworkCompatibility` = все должны иметь мод, та же версия). Положить ту же папку `AxePlates` в его `BepInEx/plugins/` (Jotunn у него уже есть). Значения бонусов (`DamagePercent` и др. с пометкой админ) синхронизируются от хоста; рецепты и вид берутся из локального конфига - держите одинаковыми.

## Совместимость
- PoV: урон считается в `ItemData.GetDamage` (постфикс с низшим приоритетом, поверх PoV/Epic Loot), уровень инструмента в `Attack.ModifyDamage` (его вызывает и ванила, и `HitBuilder` PoV). Перетаскивание: свой префикс `InventoryGui.OnSelectedItem` (у PoV свой, срабатывает только при «вооружённой» руне).
- Epic Loot, Item Drawers: чужие ключи `m_customData` не трогаются, обух - обычный материал без данных.

## Известные ограничения
- Мод не может прочитать сетку модели без включённой Read/Write; если меш головки нечитаемый, вид не появится (в логе `[plate] cannot attach ...`), бонусы работают.
- Иконка топора в инвентаре не меняется (только строка в подсказке).
- Станции/уровни и сопоставление «Громокровь/Огнельд» = Thunderblood/Frostfire выбраны мной; правятся в конфиге.
- Ничего из этого не проверено в игре: смотрите `BepInEx/LogOutput.log` (строки `plate`, `target`).

## Форма обуха и качество (обновление)
- Свой предмет «Форма обуха» (`AxePlateMold`, процедурная текстура и модель). Попадает в те контейнеры, где при создании лежит любая ванильная форма (`Mold*`), шанс `Mould.ChanceInMouldChests`. Запасной вариант: `Mould.CraftableAtForge=true`.
- Заготовка обуха: форма + золото + гвозди (станция из рецепта `AxeGoldUncooked`); закалка: станция из `AxeGold`.
- Громокровный/огнеледяной имеют качество 1-4: апгрейд на верстаке по ванильной формуле (золото +10/+20/+40, сущность +1/+2/+4), уровень станции растёт на 1 за качество. Бонусы растут по качеству (урон x1..1.14, молния x1..1.33, огонь x1..1.75, лёд x1..1.10). Громокровный: +0,2% урона за недостающее здоровье (конфиг).
