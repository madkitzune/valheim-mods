# ArcaneArmory - дизайн (решено с пользователем)

Решения:
- Масштаб: 1 оружие на вид и стадию + 2-3 на стадию у любимых видов (луки, щиты, магические посохи, боевые топоры).
- Виды: лук, арбалет, щит, магический посох, боевой топор, меч, копьё, алебарда, нож, булава/дубина (+ двуручные при необходимости).
- Стадии: Чёрный лес, Болото, Горы, Равнины, Туманные земли, Пепельные земли.
- Эффекты: из PoV (дух, молния, яд, лёд, огонь, кровотечение, накопление оглушения/слома, цепь, обездвиживание, лишняя стрела, площадь, снаряд) через Valheiman.Api + свои (метка, зона, волна, заряд).
- Основа лука: Хороший лук (Finewood) и выше; Грубый лук не используется.
- Вид: ванильная модель + процедурные детали и свечение (как обух в AxePlates); без чужих моделей.
- Сетка: данные-ориентированная (строка таблицы = оружие), ~20 переиспользуемых эффектов.

Порядок: Чёрный лес (волна 1) -> Болото -> Горы -> Равнины -> Туманные -> Пепельные; после каждой волны пакет для подруги.
Следующий шаг: исследовать Valheiman.Api (Items, CustomAffix) и ванильные префабы основ по видам и стадиям.
